## 🚀 使用方法

1. **安装扩展**：将扩展文件加载到Chrome浏览器
2. **点击扩展图标**：在浏览器工具栏点击扩展图标
3. **查看状态**：界面会显示当前的WebRTC保护状态
4. **切换保护**：使用开关按钮开启或关闭IP保护
5. **检测泄露**：点击"检测IP泄露"按钮测试保护效果

## 🛠️ 技术特性

- **Chrome Extension Manifest V3**：使用最新的扩展标准
- **现代CSS**：CSS变量、Flexbox布局、CSS Grid
