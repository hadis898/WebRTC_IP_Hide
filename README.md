# WebRTC IP保护扩展

## 功能特性

- 🔒 一键禁用WebRTC协议，防止IP地址泄露
- 🌐 支持多语言切换（中文/English）
- 🎯 实时显示保护状态
- ⚡ 快速检测IP泄露风险

## 多语言支持

本扩展现在支持两种语言：

### 中文 (默认)
- 界面完全中文化
- 适合中文用户使用

### English
- 完整的英文界面
- 适合国际用户使用

## 🚀 使用方法

### 语言切换
1. 点击扩展图标打开弹窗
2. 在右上角找到语言切换器
3. 悬停显示语言选项
4. 点击选择中文或English

### WebRTC保护
1. 打开扩展弹窗
2. 查看当前保护状态
3. 使用开关控制保护功能
4. 点击"检测IP泄露"验证效果

## 技术实现

- 使用Chrome Extension Manifest V3
- 多语言系统基于JavaScript对象配置
- 语言设置保存在localStorage中
- 响应式设计，支持不同屏幕尺寸

## 文件结构

```
popup/
├── popup.html          # 主界面HTML
├── popup.css           # 样式文件
├── popup.js            # 主要逻辑
└── languages.js        # 多语言配置
```

## 安装说明

1. 下载扩展文件
2. 打开Chrome扩展管理页面 (chrome://extensions/)
3. 启用"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择扩展文件夹

## 隐私说明

- 本扩展仅修改WebRTC隐私设置
- 不会收集任何用户数据
- 所有设置仅保存在本地浏览器中
